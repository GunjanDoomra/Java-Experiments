ShopSphere – E-Commerce Web Application

Project Description

ShopSphere is a Java-based e-commerce web application that allows users to browse products and view their prices, descriptions, and availability. It uses MySQL to store product information and Apache Tomcat to run the web application.

Technologies Used

- Java, JSP, Servlets
- HTML, CSS, JavaScript
- MySQL and MySQL Workbench
- Maven
- Apache Tomcat 11

Project Features

- Displays products dynamically.
- Shows product names, descriptions, and prices.
- Stores product information in a MySQL database.
- Provides a simple and colorful shopping interface.

Project Structure

- Java: Handles application logic.
- JSP: Displays web pages.
- MySQL: Stores product data.
- CSS and JavaScript: Improve design and interactivity.
- Maven: Manages dependencies and builds the project.
- Tomcat: Runs the web application.

How to Run

1. Configure the MySQL database.
2. Run "mvn clean package".
3. Deploy the generated WAR file to Tomcat.
4. Open "http://localhost:8080/shopsphere/" in your browser.
